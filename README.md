# WDD 231

Coursework repository for WDD 231.

## Structure

- `index.html` - Home page
- `images/` - Optimized images and SVG assets
- `styles/small.css` - Base styles for small screens
- `styles/larger.css` - Responsive styles for larger screens
- `scripts/navigation.js` - Responsive navigation
- `scripts/date.js` - Dynamic footer dates
- `scripts/course.js` - Dynamic course cards and filters
